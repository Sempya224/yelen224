# Politique de securite

## Signaler une vulnerabilite

Si vous pensez avoir trouve une faille de securite dans Yelen224, ecrivez a **{{ADRESSE_SECURITE}}**.

Merci de ne pas ouvrir d'issue publique et de ne pas publier la faille avant notre reponse.

Indiquez si possible :
- la description de la faille et son impact ;
- les etapes pour la reproduire ;
- la ou les URL ou routes concernees ;
- vos coordonnees pour que nous puissions vous repondre.

N'incluez pas de donnees personnelles reelles de citoyens. Si vous en avez rencontre par accident, ne les copiez pas et signalez-le nous.

## Ce que nous nous engageons a faire

- Accuser reception de votre message sous {{DELAI_ACCUSE_RECEPTION}}.
- Vous tenir informe de l'avancement de la correction.
- Ne pas engager de poursuites contre une personne qui agit de bonne foi, respecte cette politique et n'accede pas a plus de donnees que necessaire pour demontrer la faille.

Les engagements de delai et le cadre juridique ci-dessus sont a faire valider par Bryan avant publication.

## Perimetre

Le site et les API de Yelen224 sous {{DOMAINE}}. Hors perimetre : deni de service, ingenierie sociale, tests physiques, services tiers (Supabase, Netlify, Postmark).

## Versions prises en charge

Seule la version deployee en production est supportee.
